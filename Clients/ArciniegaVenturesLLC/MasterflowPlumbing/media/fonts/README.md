# Masterflow Web Fonts

The Masterflow site self-hosts Lato for body copy and Oswald for display type so the generated site does not depend on a third-party font request.

- Lato: https://github.com/latofonts/lato-source
- Oswald: https://github.com/googlefonts/OswaldFont

Both font families are distributed under the SIL Open Font License 1.1. Keep this notice with redistributed font files.
